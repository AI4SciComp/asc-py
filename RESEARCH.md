# ASC OS sidecar pilot

Canonical authored research state lives under `research/`. Generated harness
bundles under `.ai/generated/` are reproducible local projections and are not
authoritative.

This sidecar records the bounded development and release contracts of
`asc-py`. It does not change the Python package, add a runtime dependency, or
authorize repository mutation. Repository-local [AGENTS.md](AGENTS.md) remains
authoritative.

See [research/README.md](research/README.md) for the pilot scope, cover,
overlaps, evidence, and validation procedure.
